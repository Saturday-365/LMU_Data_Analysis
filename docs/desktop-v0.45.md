# LMU 个人遥测工作台 · 桌面 V0.45

解压整个发行目录后，双击 `LMU-Data-Analysis-v0.45.exe`。需要 Windows 64 位及 Microsoft Edge WebView2 Runtime。可继续读取原有本地档案。

## 个人赛道档案

- **最近一场正赛**显示最快圈、中位圈、统计圈数、已配对的进出站耗时、驾驶段时间线及圈速分布。若档案里只有练习或排位，则显示最近会话。缺少有效分段事件时，仍可查看有记录的整场圈速。
- **最近录制**列出最近六份录制，可直接打开单场。
- **赛道成绩**按布局、品牌和组别组织。排位显示最快圈，正赛显示中位圈、最快圈和 P10–P90。可以按遥测录制时长筛选正赛。点击品牌会打开整组的历史趋势，点击最快圈会打开对应录制和圈次。

驾驶段时间线以文件中的 `In Pits` 状态划分。进出站耗时只累计观察到完整进出站事件的区间。录制从赛中开始或提前结束时，圈数与时长都以文件覆盖范围为准。官方名次、外部排名与评分没有对应的本地统计字段。

## 构建

在 PowerShell 中运行 `.\scripts\build-desktop.ps1`。发行目录为 `dist/LMU-Data-Analysis-v0.45/`，分发时保留整个目录。
