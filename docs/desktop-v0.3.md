# LMU 个人遥测工作台 · 桌面 V0.3

> 本页记录该历史版本。当前 `main` 的运行、换机迁移和构建步骤见 [桌面版 V0.6](desktop-v0.6.md)。

解压整个目录，双击 `LMU-Data-Analysis-v0.3.exe`。需要 Windows 64 位和 Microsoft Edge WebView2 Runtime。以前的录制、调教备注和圈次仍从本地档案读取。区间库也随 `catalog.sqlite3` 备份。

## 区间复盘

1. 打开「驾驶曲线」，选择当前圈和同布局的参考圈，启用距离轴。
2. 在走线图下方找到「区间复盘」。输入起止距离，或将鼠标移到曲线、走线对应位置后点击起点或终点的「取游标」。
3. 点击「查看区间」。曲线缩放到选中区间，显示区间得失、刹车点、最低速度和回油点。点击表格里的测量值，可定位相应的距离。
4. 输入名称并点击「保存区间」。切换到同一布局的其他录制，还可以从下拉菜单加载刚保存的区间。选择已有区间后可修改并保存，选择「新建区间」即可保存另一条记录。

区间名称与边界由用户定义。刹车点是区间内从低于 5% 到达到 5% 且持续至少 0.15 秒的位置。回油点是在最低速度点之后达到 20% 并持续至少 0.15 秒的位置。最低速度由区间内的速度曲线测量，边界内插。数据有缺口、区间起点已经踩刹车或动作持续依据不足时显示相应状态。相同范围内可能有多次动作，表格使用第一处符合条件的动作。

差值列为当前圈减参考圈。刹车点和回油点的差值以米为单位，正值表示当前圈在赛道距离上更晚。累积时间差的区间得失仍按两圈共同覆盖的有效数据计算。

## 构建

在仓库根目录的 PowerShell 中运行 `.\scripts\build-desktop.ps1`，依赖清单为 `requirements-desktop.txt`。将 `dist/LMU-Data-Analysis-v0.3/` 整体分发。
