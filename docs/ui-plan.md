# V0.1 数据展示规划

状态：本地网页已实现文件导入、选圈、五类联动曲线、缩放平移和同会话双圈叠加。本文保留需求规划，实际已验收范围见 [网页说明](web-usage.md)。

已查看用户提供的 6 张 Racing Lab 参考图，采用深色界面、源圈 / 对比圈选择及同步曲线的交互方向，移除标注的 AI 面板。图片与 LMU 样本不是同一场练习，不能用图片圈时验证数据。详细映射见 [样本核验](sample-verification.md)。

## 交互

- 所有曲线共享横轴和游标，通道保持各自纵轴、单位与合理范围。
- 当前 LMU 样本的转向输入为百分比，标签使用“转向输入（%）”，不照搬参考图的角度单位。
- 鼠标移动显示对应数值，支持框选缩放、平移和恢复整圈。
- 单圈为默认视图，第二圈通过明确选择加入，不自动选择未知参考圈。
- 两圈使用不同颜色和线型，图例说明圈号；空值断开显示。
- 未知单位仍可查看原始通道，但明确标注并限制不可靠的跨圈叠加。
- 圈次或文件切换后清楚显示当前选择；防止旧图表被误认为新文件结果。
- 进出站圈、残圈、有效性未知以文本标记；不能只依赖颜色表达。
- 数据量大时可使用显示降采样，保留峰值特征，并提供原始数值查询。

## 页面状态

空状态提供文件选择入口；读取中显示进度或活动状态；失败时解释具体原因；部分通道缺失时仍展示可用数据。当前版本不设置驾驶评分、损失结论或建议面板。
