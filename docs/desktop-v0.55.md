# LMU 个人遥测工作台 · 桌面 V0.55

解压整个发行目录后，双击 `LMU-Data-Analysis-v0.55.exe`。需要 Windows 64 位及 Microsoft Edge WebView2 Runtime。可直接打开旧版档案。

## 浏览与分析

- 侧栏按录制时间排列会话，可按赛道、车型、品牌、日期或文件名搜索。使用「档案」返回时会回到先前浏览的档案视图。
- 使用「上一圈」和「下一圈」切换当前圈。「关闭对比」可回到单圈。圈次加载失败时，可直接在曲线旁重试。
- 选择可按距离比较的参考圈后，在曲线上拖选区间，或在曲线或走线上依次标记两端。新标记从新建区间开始，需保存后才会加入区间库。「区间结果」可跳转到复盘指标，「清除区间」移除高亮并恢复全圈视图，Esc 取消正在进行的标记。
- 批量导入完成后会更新档案与导入报告。可以继续在当前会话分析。

## 构建

在 PowerShell 中运行 `.\scripts\build-desktop.ps1`。发行目录为 `dist/LMU-Data-Analysis-v0.55/`，分发时保留整个目录。
