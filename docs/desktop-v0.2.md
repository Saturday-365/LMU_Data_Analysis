# LMU 个人遥测工作台 · 桌面 V0.2

> 本页记录该历史版本。当前 `main` 的运行、换机迁移和构建步骤见 [桌面版 V0.6](desktop-v0.6.md)。

解压整个发行目录后，双击 `LMU-Data-Analysis-v0.2.exe`。应用面向 Windows 64 位，运行需要 Microsoft Edge WebView2 Runtime。桌面版沿用 V0.1 的本地档案和数据目录 `%LOCALAPPDATA%\LMU Data Analysis`，原有练习、遥测和补录可以直接读取。

## 节奏与调教

1. 打开一条会话记录并选择「节奏与调教」。逐圈图的横轴是录制经过时间。点击圈速点或驾驶段的最快圈可以回到驾驶曲线。
2. 查看「连续驾驶段」的中位圈、标准差和 P10–P90。段界使用 `In Pits` 的观测状态与进出站变化。首尾若只看到录制边界或首次观测，界面会标明。进出站圈、残圈和缺计时圈均排除在驾驶段节奏统计之外。
3. 调教对照的 A 侧为当前会话。B 侧可选同赛道布局、车辆和会话类型的录制，或同会话的另一个驾驶段。两侧可以查看最快圈、中位圈、分布和差值。
4. 在「练习信息」按整场或圈次补录调教名称。对照按纳入统计的圈显示有效标签和未标注数量。油量、气温、赛道温度、轮胎和游戏版本按整场列出。

P10–P90 使用至少 5 圈的样本，以线性插值计算。前后节奏差使用至少 6 圈，计算末 3 圈与首 3 圈的中位数之差。调教 A/B 展示实测结果，环境、燃油和驾驶差异都可能改变圈速。游戏官方有效性仍为未知。

## 构建

在仓库根目录的 PowerShell 中运行 `.\scripts\build-desktop.ps1`，依赖见 `requirements-desktop.txt`。发行目录为 `dist/LMU-Data-Analysis-v0.2/`。首次配置环境与现有档案备份步骤见项目的桌面 V0.1 文档。
