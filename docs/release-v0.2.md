# V0.2 本地实现与验收

日期：2026-09-17。保持已确认范围，未加入跨练习对比、连续时间差、逐弯导航、训练任务或 AI 教练。此记录描述本地工作区实现，不表示已提交、推送或创建发布标签。

## 已实现

- 新增“练习信息”页，包含车辆、练习、环境、车况、调教五组；支持整场和指定完整圈的补录、来源展示、修改时间、自动值查看及恢复。
- 自动读取元数据和通过单位、频率、行连续性及数量核验的气温、赛道温度、风速、风向原始角值、燃油。整场与每圈分别提取范围，真实零值不视为缺失。
- 顶部显示条件及原始录制时间摘要；双圈选择下展示各圈温度、燃油、轮胎和调教名称。没有录制日期时侧栏明确标记导入日期，不冒充录制时间。
- 天气元数据快照与动态天气分开；调教、轮胎、辅助和湿度等字段语义未核实的内容明确为未知，不推断默认调教、干地或无损伤。
- SQLite 版本 1 → 2 增量迁移，旧数据升级前使用 SQLite 备份接口保存 `catalog.sqlite3.pre-v2-<随机编号>.bak`；迁移使用事务，失败回滚，保留原编号。新附加信息和赛道资源关联独立保存。
- 赛道资源接入脚本、来源及配准证据检查、图层开关和地图底层绘制；来源不全、布局不符、坐标不符、误差超限或资源缺失时降级。原有曲线、计时和轨迹接口兼容。

## 使用与兼容性

重启本地服务并刷新网页；入口仍为 `start-web.cmd`。第一次使用 V0.2 会升级目录数据库，旧练习无需重新导入。详细字段、覆盖优先顺序和接口见[练习信息约定](practice-fields-v0.2.md)。

自动升级备份只有目录数据库；完整备份需停止服务后复制整个 `data/`。如需回到 V0.1，应先停止服务、另存 V0.2 数据目录，再使用升级前目录数据库备份配合原始 recordings；V0.1 不支持版本 2 数据库，升级后的补录不会出现在旧版备份中。

所有新增数据仅存本机，无新增账号、云同步或网络外传。使用已核验资源接入脚本也不会下载或发布赛道资产。
