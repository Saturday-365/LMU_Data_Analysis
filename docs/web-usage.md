# 本地网页端

## 启动

首次安装（Python 3.12）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

双击根目录 `start-web.cmd`，保留启动窗口，打开 **http://127.0.0.1:8765**。此电脑已安装依赖。关闭窗口或按 Ctrl+C 停止服务。

也可运行 `.\.venv\Scripts\python.exe scripts/serve_web.py`。端口被占用时附加 `--port 8766`，访问对应地址。可通过 `--data-dir` 更换存储目录，默认是项目内 `data/`。

## 操作

1. 点击或拖入 LMU 原生 `.duckdb` 文件，每次一份，最大 128 MB。
2. 左侧选择练习记录，再选择当前完整圈。首尾不完整片段不混入完整圈。
3. 可叠加同一练习记录内的参考圈：橙色实线为当前圈，青色虚线为参考圈。
4. 切换距离 / 圈内时间。只有所选圈距离可靠且单调时允许距离轴，否则回退时间。
5. 移动鼠标查看五条曲线同位置数据；滚轮缩放、拖动平移、双击或“重置视图”恢复全圈。聚焦曲线区域后可用左右方向键移动游标。
6. 展开读取状态查看诊断。转向单位为百分比，缺失值为空，挡位以阶梯显示。

游标展示最近的对齐采样值及采样 / 插值 / 保持标记。两圈按各自距离绘制，不生成自动驾驶结论。源采样相位与官方圈有效性仍未核实，“最短记录圈”不表示官方有效最快圈。

## 保存和备份

页面顶部可切换三个视图：

- **驾驶曲线**：现有单圈 / 双圈五类通道。
- **圈速总览**：全部圈次、S1 / S2 / S3、距最快圈差值、平均 / 最快 / 理论最快 / 标准差，以及最优分段的来源圈次。残圈单列，缺失值留空。
- **数据目录**：检查文件里的全部连续通道与事件，支持搜索及候选 / 常量 / 待核实筛选。此页是原始数据清点，不表示所有通道图表均已实现。

旧记录无需重新导入。圈速页可通过 `http://127.0.0.1:8765/#timing` 直接打开。统计口径和 Monza 样本结论见 [扩展数据与分段核验](telemetry-opportunities.md)。

- `data/catalog.sqlite3` 保存本地车手、练习、圈次和稳定编号。
- `data/recordings/<UUID>.duckdb` 保存原始文件副本，源文件不变。
- 相同文件重复导入会打开已有记录。重启服务后列表仍可读取。
- `data/` 整体被 Git 忽略。备份前停止服务，再复制整个目录；只备份目录数据库不足以恢复曲线。
- 原始副本仍含游戏写入的所有字段；展示接口仅返回元数据白名单，不返回源车手名、Steam ID 或车辆调校。

此版本只监听本机 `127.0.0.1`，没有账号登录、联网同步或云备份。云端替换边界见 [架构说明](architecture.md)。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:LMU_SAMPLE_PATH = '真实样本绝对路径.duckdb'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

未设置样本路径则跳过真实样本检查。修改前端文件后刷新浏览器，修改 Python 服务端后重启。
