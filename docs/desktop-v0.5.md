# LMU 个人遥测工作台 · 桌面 V0.5

> 本页记录该历史版本。当前 `main` 的运行、换机迁移和构建步骤见 [桌面版 V0.6](desktop-v0.6.md)。

解压整个发行目录后，双击 `LMU-Data-Analysis-v0.5.exe`。需要 Windows 64 位及 Microsoft Edge WebView2 Runtime。旧版档案可继续使用。

## 批量导入

- 内容相同的遥测会被拒绝，文件改名后仍可识别。检查范围是当前本地档案。
- 录制时长以遥测时间轴首尾为准。新文件须达到 60 秒，并包含至少 1 个完整圈。
- 每份文件单独处理。结果会列出已导入、重复拒绝、已过滤和失败的数量，展开可查看原因。

V0.46 的 GPS 采样间断处理继续适用。录制可在存在采样间断时导入，曲线和走线会在缺口处断开。

## 构建

在 PowerShell 中运行 `.\scripts\build-desktop.ps1`。发行目录为 `dist/LMU-Data-Analysis-v0.5/`，分发时保留整个目录。
