## 下载与启动

1. 在 [V0.71 发布页](https://github.com/Saturday-365/LMU_Data_Analysis/releases/tag/v0.71) 下载 `LMU-Data-Analysis-v0.71-win-x64.zip`。
2. 将 ZIP 完整解压到一个独立目录。
3. 双击 `LMU-Data-Analysis-v0.71.exe`，保留同目录的 `_internal/`。

桌面版需要 64 位 Windows 和 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。发行包已包含应用运行所需的 Python 组件。

## 导入遥测

在游戏中启用原生遥测录制，完成一段驾驶并等待游戏写完文件。游戏内设置、文件位置和通道选择见 [LMU 官方遥测录制说明](https://guide.lemansultimate.com/hc/en-gb/articles/14524956311695-Telemetry-Recording)。

| 方式 | 操作 |
| --- | --- |
| 手动导入 | 点击侧栏的「批量导入遥测」，或将一个或多个 `.duckdb` 文件拖入导入区。 |
| 启动扫描 | 在「设置」选择游戏遥测目录并保存。应用启动时扫描该目录直接包含的文件，优先处理最近更新的录制。 |
| 立即扫描 | 在保存目录后点击「立即扫描」。设置页会显示新增、重复、过滤和待重试结果。将目录留空保存可关闭启动扫描。 |

每份文件最多 256 MiB，录制至少 60 秒且包含至少一个完整圈。内容相同的文件即使改名也会识别为重复。游戏原始文件保存在原处，软件在本机档案中保存导入副本。

## 车手成长

从「个人圈速」进入「车手成长」，在右上角选择赛道布局。同一布局的所有车型和会话类型汇总到一张图表，按录制时间排序并等距显示。窗口较窄或录制较多时可横向滚动。

- **橙色实线**是每场最快圈，**青色虚线**是每场最快 5 圈的算术平均。
- 鼠标悬停在点上可查看对应圈时、准确录制时间和车型。缺少补录车型时，显示游戏记录的车辆标识。
- 明细表保留每场录制，点击最快圈可进入该圈的驾驶曲线。缺少录制时间的会话列在表格末尾。

统计使用有圈时且无已知进站状态的完整圈。少于 5 个统计圈时，最快 5 圈平均显示为「—」。天气、车种和比赛条件都可能影响圈速。接力录制按文件统计，结合实际驾驶时段判断个人成绩。

## 圈速复盘

首页「最近录制」可更新左侧会话预览。点击「打开会话」后，可切换下列视图。

| 视图 | 使用方法 |
| --- | --- |
| 驾驶曲线 | 选当前圈及可选参考圈，使用距离或圈内时间对齐。滚轮缩放，拖动平移，「全圈」恢复。可标记区间，查看区间内的驾驶数据和用时差。 |
| 圈速总览 | 查看每圈、S1 / S2 / S3、理论最快圈和统计。单独列出残圈。 |
| 节奏与调教 | 查看每圈节奏、进出站和驾驶段分布，也可选择可用的对照录制。 |
| 数据目录 | 搜索录制中的通道、单位和事件。 |
| 练习信息 | 检视源数据和补录值，按整场或圈次记录车型、天气、轮胎等信息。 |

在「个人赛道档案」使用「导出全部圈速 CSV」，可导出档案中的完整圈。距离对齐、GPS 和分段等视图的可用性取决于源文件通道。软件保留读取诊断和未知值，LMU 官方圈次有效性保持未知。

## 备份、升级和换机

默认档案目录为 `%LOCALAPPDATA%\LMU Data Analysis`。以 `--data-dir` 启动时，档案位于指定目录。

1. 退出软件。备份时复制整个档案目录，包括 `catalog.sqlite3`、`recordings/`、本机设置和已有赛道资源。
2. 同一电脑升级时，将新版解压到独立目录后运行。软件会读取同一账号下的档案。以前使用 `--data-dir` 的，继续指定同一路径。
3. 换电脑时，将档案目录复制到新账号对应的路径。目标电脑已有档案时，先分别备份。首次启动后检查会话和曲线可打开，并在「设置」更新游戏遥测目录。

桌面程序目录和档案目录独立。保存原始游戏录制时，可额外备份游戏自己的遥测目录。

## 常见问题

**双击 EXE 后没有打开窗口**

确认已完整解压，以及 WebView2 Runtime 可用。同一个档案只能由一个桌面窗口打开。如果仍无法启动，可在档案目录查看 `desktop.log`。

**为什么某些录制显示重复、已过滤或待重试**

重复表示档案已有同内容的文件。已过滤常见于录制少于 60 秒或缺少完整圈。文件还在写入时，等待写入结束后可再次扫描或手动导入。

**为什么没有 GPS 走线、区间结果或最快 5 圈平均**

GPS 和对齐分析需要对应通道。最快 5 圈平均至少需要 5 个统计圈。可打开「数据目录」或读取诊断检查文件中可用的通道。

**怎样报告问题**

请附上软件、LMU 和 Windows 版本、复现步骤、受影响的会话或通道，以及去除个人信息后的截图或日志片段。公开提交的遥测样本请先确认共享授权。原生文件可能含游戏写入的身份和调教信息。[问题反馈](https://github.com/Saturday-365/LMU_Data_Analysis/issues/new/choose)

## 从源码构建

在 Windows 安装 Git 和 Python 3.12。对应发行版的源码位于 Git 标签 [v0.71](https://github.com/Saturday-365/LMU_Data_Analysis/tree/v0.71)。

```powershell
git clone https://github.com/Saturday-365/LMU_Data_Analysis.git
Set-Location LMU_Data_Analysis
git checkout v0.71
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\scripts\build-desktop.ps1
```

运行 `dist/LMU-Data-Analysis-v0.71/` 中的 EXE。将整个目录压缩成 ZIP 可在其他 64 位 Windows 电脑使用。项目使用 GPL-3.0-only，发行包附带许可证和第三方声明。

已有源码时，退出正在运行的软件，用 `git fetch --tags` 更新版本标签，切换到目标版本，重新安装该版本的依赖后再构建。
