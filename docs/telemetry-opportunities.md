GPS 后续核验：按球面局部平面近似（R = 6,371,000 m，经度乘原点纬度余弦）投影，使用同一录制固定原点。由连续坐标推算的速度与 Ground Speed 在车速 > 80 km/h 样本上的比值中位数约 1.0004，10% / 90% 分位约 0.964 / 1.037。四个完整圈轨迹长度约 5.72～5.77 km；纬度最小步长为 0.0000038147°，约 0.42 m。支持局部走线可视化，不支持把这些坐标当作经过验证的真实地理位置或亚分米测量。

## 分段语义与计算

Current Sector 的实际变化顺序为 `1 → 2 → 0 → 1`，其中 0 对应第三段。Current / Last Sector2 是从本圈起点到第二分段终点的累计时间。例如第 1 圈累计 Sector2 = 76.592773 秒，与第二段切换时刻距起点的 76.58 秒一致。

- S1：使用该圈记录的 Sector1。
- S2：累计 Sector2 减 S1。
- S3：该圈 Lap Time 减累计 Sector2。

先按圈起止与分段切换事件核对归属，允许 0.05 秒的事件采样误差；不以采样间隔替代高精度计时值。当前 / 上圈字段冲突、单位错误、无边界或缺少事件时保留空值，不沿用上圈。不能直接把命名为 Best Sector 的字段当作全程各段独立最优；本样本这些字段随最快整圈变化。

统计范围为当前练习中有已记录圈时、不含维修区状态的完整圈；出站圈、末尾残圈和计时异常片段只列出，不进入统计。末尾残圈可核对的 S1 = 53.301 s、S2 = 40.121 s，S3 / 整圈保持缺失。游戏对圈次的有效 / 删圈判定尚未确认。
