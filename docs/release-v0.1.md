# V0.1 交付记录

完成日期：2026-09-17。用户确认当前版本完成，交付形式为 Windows 本地运行的网页应用，版本标签为 `v0.1.0`。

## 已交付

- LMU 原生 DuckDB 遥测只读导入、本地持久保存及圈次选择。
- 速度、油门、刹车、转向、挡位曲线，同步游标、缩放、平移和双圈对比。
- 基于经纬度的两圈走线叠加、曲线双向联动及弯道跟随。
- 圈速与分段总览、平均圈速、理论最快圈及分段来源。
- 原始通道和事件目录；缺失、未知和不支持的数据明确提示。

## 验证与限制

此前实现阶段的 48 项自动化检查通过，真实 Monza 样本四个完整圈的圈时已由用户确认；走线与曲线联动已在浏览器检查。本次版本收尾只更新文档和 Git 版本状态，未重新执行测试。

GPS 为样本原生 10 Hz，局部投影不代表真实地理底图或厘米级精度。官方圈有效性、连续通道精确采样相位及部分频率偏差尚未核实；具体游戏版本号仍未知。长会话性能、更多车辆 / 赛道兼容及原计划未完成的专项验收继续留在路线图，不标记为通过。

提供本地网页启动方式，未提供 Windows EXE、云端同步或 AI 驾驶建议。原始私有样本、本地数据库及个人数据不随源码发布。
