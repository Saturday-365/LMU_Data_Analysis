# V0.1 范围与验收

状态：设计草案，尚未实现。目标平台优先 Windows。

## 用户流程

选择本地文件 → 查看读取结果 → 选择圈次和通道 → 查看、缩放图表 → 可选第二圈叠加对比。

## 必须具备

| 功能 | 行为 | 验收重点 |
| --- | --- | --- |
| 文件导入 | 优先支持 LMU 原生 `.duckdb` | 以只读方式打开；源文件内容不变 |
| 结构检查 | 识别支持的结构，列出缺少的必要数据 | 不仅凭扩展名判定支持；结构未知时明确报错 |
| 会话概览 | 展示可取得的车辆、赛道、时间范围及圈次 | 未知值标为未知，不推测补全 |
| 圈次列表 | 圈号、圈时、完整性；有效性仅在有依据时显示 | 不把完整圈等同于有效圈；首尾残圈单独标记 |
| 通道选择 | 列出实际存在的通道与单位 | 区分缺失、空值和真实零值 |
| 同步曲线 | 速度、油门、刹车、转向、挡位按可用性展示 | 共享游标和横轴；可缩放、平移及恢复视图 |
| 数值查看 | 游标处显示数值和单位 | 区分原始样本与插值结果 |
| 异常提示 | 空文件、损坏、被占用、未知结构、无完整圈 | 提供可理解的信息；不破坏源文件 |

## 条件性展示

- 数据有可信的圈内距离时提供距离横轴；否则保留时间横轴并说明原因。
- 同车同赛道且圈次结构可比较时允许叠加两圈；条件不足时说明限制。
- 两圈对比只展示曲线和数值；V0.1 不自动归因、不输出驾驶建议。
- 其他温度、燃油、轮胎、能量等通道在完成字段核对后逐步加入；不承诺每种车都具备全部通道。
- 赛道地图暂为后续候选功能，不是 V0.1 发布门槛。

## 明确不在范围内

- AI 模型、自然语言教练、自动驾驶或硬件控制。
- 逐弯诊断、刹车点好坏判断、自动损失排名和最佳操作推荐。
- 实时共享内存接入、游戏覆盖层、远程遥测传输。
- 云存储、账户、在线排行榜、公开参考圈库。
- 多游戏兼容、直接读取回放视频或未知厂商数据包。

## 发布前证据

至少使用已获授权的真实 LMU 文件核对：正常完整圈、首尾残圈、缺失通道，以及不同采样频率的处理。人工比对原始数值、图表游标值和圈时；记录单位及误差来源。解析和展示验收通过前不宣称支持所有 LMU 文件或所有车辆。
